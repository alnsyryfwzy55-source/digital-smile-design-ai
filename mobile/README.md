# تطبيق أندرويد (Flutter) — يعمل دون إنترنت

التطبيق نفسه الموجود في `docs/`، مضمَّناً داخل تطبيق أندرويد ويُخدَّم على الجوال (`http://localhost:8765`).
نموذج الأسنان وكاشف الوجه والمحاكاة كلها تعمل على الجوال، والحالات تُحفظ على الجهاز.

## الحصول على الملف APK
يُبنى تلقائياً على GitHub Actions عند كل تغيير في `docs/` أو `mobile/`، ويُنشر في صفحة **Releases** للمستودع
(وأيضاً في Actions ← آخر تشغيل ← Artifacts). نزّل `app-release.apk` على الجوال وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## البناء محلياً
```bash
cd mobile
flutter create --platforms=android --org com.alnusairi --project-name smile_design .
bash tool/prepare.sh
flutter pub get && dart run flutter_launcher_icons
flutter build apk --release
```

## ما يختلف عن نسخة الويب
- المشاركة والتنزيل يفتحان قائمة المشاركة في أندرويد (حفظ أو إرسال)، والطباعة تفتح طباعة أندرويد (ومنها حفظ PDF).
- لا يحتاج إنترنت إلا لميزة «خادم التحليل» الاختيارية.
- التوقيع: نسخة الإصدار موقّعة بمفتاح التصحيح الافتراضي (للتجربة والاستخدام الداخلي)، وتحتاج مفتاحاً خاصاً قبل النشر على متجر Google Play.
